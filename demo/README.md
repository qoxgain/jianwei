# P0.1 浏览器交互演示

下载同目录 `jianwei-p0.1-demo.zip`，解压后用 Chrome、Edge 或 Firefox 打开 `index.html`；也可直接下载 `jianwei-p0.1.html`。无需安装依赖或联网。企业浏览器限制本地文件时，按压缩包说明启动本机静态服务。

这是明确标记的浏览器演示。默认加载研发手册示例知识，可编辑动作/SOP、验证输入、预览差异、保存候选版本。候选只写浏览器本地存储；没有连接服务器，也不产生任何真实视频识别结果。浏览器禁止本地存储时会显示提示。

真实后端版本使用根目录 README 的启动命令，候选版本存入 SQLite 数据库。

建议验收：

1. 查看场景概览，确认真实视频/训练/评测均未执行。
2. 进入动作与 SOP，修改“检查口袋”的名称或证据描述。
3. 预览变更，确认稳定动作 ID 保留、变更字段和后续影响清楚。
4. 保存候选版本，刷新页面查看历史；源知识保持基准，候选尚未发布。
5. 切换 YAML 编辑，输入重复字段或不合法 SOP 引用，确认不能保存。
6. 查看环境检查：demo 可运行；lab/site 必须显示各自缺少的数据、权重或服务条件。
