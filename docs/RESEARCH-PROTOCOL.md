# P0.3.5 研究协议与独立会话验收

真实研究先登记协议、采集来源和分区，再训练候选，最后运行一次封存评估。协议预览是只读检查；填写了协议不等于数据已获准，也不等于学习效果成立。现有九段录像已用于开发，继续作为开发资料，不能重新命名成新的封存测试。

## 登记与冻结

运行参数仍只来自 `config/system.yaml`。在 `temporal.research_protocol` 中明确填写：

| 字段 | 含义 |
|---|---|
| `protocol_id` | 本次研究的问题与协议版本标识 |
| `registered_by` / `registered_at` | 实际登记人和带时区的登记时间，不能代填为已审核 |
| `primary_metric` | 固定为 `source_macro_mse`：先对同一会话的预测跨度求均值，再对会话等权 |
| `min_independent_sessions` | 事先确定的测试独立会话下限，至少 2；软件下限不保证统计充分性 |
| `minimum_relative_improvement` | 事先确定的相对改善门槛，范围 `[0, 1)` |
| `confidence_level` | 区间置信水平 |
| `bootstrap_replicates` / `bootstrap_seed` | 有界重采样次数及固定种子 |
| `controls` | 固定为 `persistence`、`shuffled_ridge` 两个对照，不能事后删去不利对照 |
| `source_sha256s`（可选） | 研究采用的规范来源名单；同会话有原片、转码等多份文件时显式选择一份，谱系登记仍保留 |

研究协议与 `temporal.dataset_manifest` 中经过审查的来源记录分开。后者记录真实采集时间、机位、视角、会话、根来源、分区及近重复核查。未知数据保持空值，软件不能确认现场记录的真实性。

页面“时序研究 → 研究协议”及 `GET /api/scenes/{scene_id}/temporal/protocol` 提供当前配置的只读预览和 JSON 导出。它不加载向量、不创建任务、不写回配置。预览有缺项时显示阻断原因；实际训练仍会重新检查。

正式训练在拟合前绑定协议、完整分区名单、配置、知识、代码和训练输入快照，并保存在 `protocol.json` 与模型记录中。源清单、特征、采样、预测跨度和阈值变化需要新的版本。登记时间是配置声明；服务端冻结记录说明实际何时创建任务，不能把自行填写的历史时间当作外部认证的预注册证明。

## 封存数据的使用

训练只读取 train/calibration。正式测试必须匹配冻结的完整 test 名单和视角/特征空间，不允许挑选其中表现好的来源。预检不得用测试窗口或分布选择协议。

真实封存测试在任务准入时保留使用记录，在首次读取特征前记录已消费；读取后即使任务失败，也不能通过重试、更换模型或更换协议重新使用同一批数据做新的验收。幂等请求可以取回原任务和报告。原模型、原报告及失败原因保留，修订模型后另采新的封存录像。

这些约束作用于同一持久化数据库及其审计记录。它们不是生产权限或防篡改系统；删除数据库、离线人工查看录像等外部操作不会被软件自动识别。现场仍须管理数据访问和封存记录。

## 统计口径与门槛

每个经过核验的独立采集会话等权。重采样单位是整个会话，所有模型使用同一组抽样索引；同一视频里的重叠窗口不增加独立样本数。每个预测跨度保留归一化特征 MSE、原空间余弦相似度、匿名状态 NLL/Brier，以及会话均值和区间。

主要对照量为：

`相对改善 = (对照的会话等权 MSE − 已选模型的会话等权 MSE) / 对照的会话等权 MSE`

两项对照的配对 bootstrap 区间下界均严格超过预登记门槛，才能得到本研究的 `passed`。区间描述有限独立会话下的不确定性，不是动作识别准确率，也不证明外部工位泛化。会话太少、对照分母为零或无法形成有效估计时返回 `blocked` 和空区间，不能输出虚假置信度。

| 状态 | 含义 |
|---|---|
| `blocked` | 协议、独立会话或可定义的估计不足 |
| `failed` | 可以评价，但没有满足事先固定的双对照门槛 |
| `passed` | 此次独立测试满足该协议的数值门槛，仍需审阅研究设计及适用范围 |
| `not_final` | 校准统计，只供候选选择，不能成为最终研究结论 |
| `mechanism_only` | 合成数据的机制检查，不是真实学习效果 |

研究门槛不会自动激活模型、修改 SOP 或准入 P0.4。SOP 章节映射、画面观测、模型预测和人工结论仍分别保存；扭矩、电性能等要求继续依赖可追溯仪器证据。

## 当前素材的核对

使用 `python -m scripts.audit_research_protocol --help` 查看只读审计命令。命令可以对已提交的真实来源清单核对缺失字段、特征版本和协议状态；不读取特征值、不训练，也不把同一来源的多次提取算成独立会话。

P0.3.3 九份稀疏提取清单和 P0.3.4 的短片密采样清单合计十个版本记录，仍只有九个原视频来源。两个版本使用不同的编码器/采样哈希，不可混用缓存。短片已有 16 个因果窗口只是时间覆盖证据，采集与独立分区要求仍须补齐。
