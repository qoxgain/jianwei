# R02-1 保存点提交闸门

基线真实连接/线程屏障复现RELEASE[s]与RELEASE"s"：执行前故障标记已fsync，独立连接仍读1行。不是原始数据库自然损坏。

词法识别改为SQLite的ASCII关键字边界而非按空白分词，覆盖标识符紧邻、各种引用、BOM/空语句/注释；再由SQLite原生authorizer识别实际COMMIT/RELEASE动作，未持提交租约的提交拒绝。authorizer不可通过受管理接口替换；正常BEGIN等待不持提交闸门，保持既有写锁顺序。

33项专项及旧可靠性通过，包括8种释放语法、故障先持久化后释放0行、提交先进入闸门后故障保留1行、真实线程屏障、spawn、嵌套回滚/释放和取消。SQLite已经提交的数据不会被后发故障倒退；不支持的控制形式若未持租约则fail closed，不默默直通。
