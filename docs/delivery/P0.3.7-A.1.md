## 关键设计与兼容性

### 公开发布闭包

`apps/web/browser-files.json` 逐文件固定公开客户端源码、配置、知识、schema、专用static资源及安装依赖摘要，绑定lockfile。清单不是按父目录/后缀自动放行；`scripts.refresh_web_manifest`只刷新已有条目，增加文件必须单独审查。禁用默认publicDir，默认目录内任何未知文件都不会隐式复制。

`reviewedAssets.ts`在开发HTTP、模块解析/加载、HTML和构建边界检查独立普通文件、realpath及SHA。Vite优化依赖仅允许实际metadata声明且来源匹配受审依赖的成员。构建记录实际成员摘要，`ReviewedStaticFiles`及Vite preview逐项复核，缺清单则静态访问关闭；API仍可运行。开发/preview脚本默认只监听loopback。

这是受信任Git/lockfile/安装与发布清单下的媒体边界，不是任意管理员代码执行的沙箱。不能将所有未知依赖文件默认为可发布文件。

### 租约和封存生效点

`FileGate.async_hold`使用非阻塞flock加异步轮询，等待不占共享AnyIO线程。HTTP/SOP进入同步工作前先取租约，使用ContextVar把已持租约授给该有界同步调用。同步后台取锁不再持进程内RLock睡眠。取消和异常通过finally关闭锁描述符；FileResponse取消有真实文件关闭检查。

`media_access`为可选统一配置：普通等待5秒、正式封存等待30秒、轮询0.01秒，均有界。超时503，不读取媒体。旧配置未设该字段时保持历史快照兼容。

| 状态 | 普通媒体访问 | 生效语义 |
|---|---|---|
| development | 允许 | 无有效封存意图或正式封存 |
| pending_seal | 拒绝新授权 | test导入意图入队DB提交立即生效，SourceSplit可仍unassigned |
| sealed | 拒绝 | 正式SourceSplit/已提交清单或同源封存图生效；优先于失败/取消 |
| seal_failed | 允许，除非还有别的pending/sealed | 失败/blocked终止该请求意图，不永久污染开发来源 |
| cancelled | 允许，除非还有别的pending/sealed | 取消意图生效；成功封存后的取消不unseal |

已经在pending之前完成授权的流可以结束；不能追回先前字节。**正式test提交必须等流租约释放**，新请求立即因pending拒绝。这是明确的两阶段顺序，没有推迟test保护。重试重新建立pending。新增只读 `GET /api/scenes/{scene}/imports/{id}/media-admission` 返回状态，不读取视频或特征。

### SQLite受支持的写入能力

词法识别匹配SQLite关键字边界，不依赖空白分词；原生authorizer确认COMMIT/RELEASE必须处于健康提交闸门内。Python commit、context、SQL COMMIT/END/RELEASE和原生mode切换保持同一故障先后顺序。BEGIN IMMEDIATE等等待不持提交闸门，避免锁顺序倒置。

受管理DBAPI改为组合外观，driver、cursor.connection、execute返回值及context都不泄露受支持的原生备份目标。原生backup不会调用目标authorizer，因此仅覆盖Python backup方法不足以修复。批准的 `Database.backup()`持内部能力、健康检查、独占创建新文件、完整性核验；不能覆写原库、自动恢复或清理隔离/测试消费记录。迁移备份保持原行为。

**历史database disk image is malformed根因仍未确认。** 本次修的是可复现事务隔离旁路，不代表修复原始磁盘损坏。私有反射、非受管SQLite写者、管理员复制文件均不属于支持接口；任意外部旧备份恢复到新数据库身份必须离线核对封存消费台账，不能据此重新开放已消费数据。

### 工具配方

保留正确的FFmpeg/FFprobe实际内容前后重哈希，补充首次定位/哈希后异常失败。任务开始前确实缺工具仍可在不依赖该工具的路径记录unavailable。工具核验期间异常抛FEATURE_TOOL_PROBE_FAILED，不返回可复用快照。新执行配方为 `p037-a1-feature-production-v4`；v1/v2/v3配方、旧缓存和权重保持不变。
