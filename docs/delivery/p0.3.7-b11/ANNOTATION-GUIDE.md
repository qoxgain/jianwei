# B.1.1 真人标注与36候选复核操作清单

协议草案b11-visible-boundaries-v1。本轮没有真人标注，这份清单不是已经完成的审核。标注负责人应先确认下列观察定义；如需要改变定义，记录新的协议/标注版本，不悄悄修改已封存真值。

1. **先独立标注。** 人员不先看旧候选、曲线、候选数量或他人的标注。使用新浏览器档案，打开Demo，进入“动作边界盲标注”；若本人已接触过这些信息，主动标记辅助标注，新浏览器不能使记忆重新变盲。界面的曝光记录只是辅助，身份、时间和是否独立仍属自报。
2. **只提供原片与源PTS。** 在有授权的开发工作区，用prepare_b11_annotation读取已登记的B.1 runtime配置，输出新的源JSON；不要给盲标人算法报告。载入源描述后选择原视频，确认SHA和显示尺寸，检查始、中、末及可变帧时间。它不需要向浏览器上传任何媒体，也不自动读取正式封存源。
3. **先统一可观察定义。** onset为可见操作开始，offset为可见操作停止；pause为同一操作的中断，switch为标注负责人有依据确认的工步改变。不要把任意衣物晃动都当工步完成，视频不能证明扭矩/电性能等仪器结果。停顿最短持续时间、操作粒度及多义情形须由标注负责人先约定，写入备注并随标注版本保存；未约定清楚时标无法判断，不强猜。
4. **全片审核。** 播放/暂停、上一帧/下一帧或原始PTS时间轴定位。手工添加边界；需要纠正时修订/删除，历史操作保留。记录人员、边界类型和备注。相同PTS多个真值须人工裁定唯一时间边界及备注，不由工具合并；当前模型只评价时间边界，不能同时声称起止或工步语义分类正确。
5. **显式记录范围。** 通过“记录人工区间”标记已审核范围和无法判断、遮挡、光照/阴影、无动作。灰色未审、绿色已声明审核、橙纹未知/遮挡。播放过不等于审核过；原片最后0.5秒虽然没有完整主特征窗口，仍必须检查和标注。首次封存缺末尾审核会被拒绝。
6. **不美化评价。** 未知/遮挡在全部方法使用同一排除掩码，比例必须报告；光照/阴影、无动作、背景无效不自动删除误检。区间可重叠，干扰计数不能相加充当总数。不能看完结果后添加排除区间并仍自称原独立盲标。
7. **封存并备份。** 勾选完整范围及真人来源声明，封存版本，导出JSON。源SHA、PTS摘要、annotation_id/revision/时间/操作人员、sealed_hash与父版本保留。封存是工具内只读与内容摘要，不是身份认证、防篡改数据库或可信时间戳；本机存储可能被清理，导出文件是必要备份。修改须新草稿，旧封存文件保留。
8. **第二位独立人员（如有）。** 对方使用单独环境独立完成全片、同一观察定义、同一原片/PTS，不看第一位结果。第一位封存后才导入第二文件。查看固定±500ms时间和类型分歧，真人裁定；工具不自动合并为共识。查看他人结果后的新版本必须标assisted，不能把协商后的一致性当原独立一致性。没有第二人员时明确blocked，不编造。
9. **再匹配原36候选。** 用analyze_b1的--frozen-report方式，不从新代码重新生成候选；使用B.1原始报告原字节，不能用文本编辑器重排格式后冒充同文件。真人覆盖完整、封存、声明来源有效后才能评价。主规则固定±500ms，附±250/1000ms敏感性；不挑最有利容差或修改主阈值。
10. **检查每个失败。** 载入CLI评价，逐方法查看匹配误差、误检、漏检、重复附近候选、干扰时段和无完整窗口尾部。点击PTS回到原片。每个方法用相同真值/范围/掩码。仅确认推荐点没有漏检真值，不得据此计算Recall/F1。没有动作真值的完整片段也不能产生虚构的完美F1。
11. **背景后验补充单独进行。** 先保留首次独立标注，再在辅助审核中检查原背景框污染、逐段记录无效范围。需要新背景时，在提取前写下坐标、完整可见范围、审核人、与旧ROI的区别和全部原采样参数；导出新system.yaml，在新目录提取。旧ROI及不利结果不得删除。未经全片检查的角落不能称纯背景；目前新干净背景实验blocked。不得只对背景方法删掉不利时段后与全片操作方法比较。
12. **交付人工结果后停止决策。** 现有录像反复用于开发，所有指标只属回顾性探索。未有完整真人标注时真实P/R/F1为null；标注完成也不意味着独立泛化或正式P0.4通过。根据完整结果由用户决定是否进入B.2，本工具不自动准入。

在仓库根目录执行（输出需新文件，保持工业材料本地）：

```bash
.venv/bin/python -m scripts.prepare_b11_annotation --config artifacts/p037-b1/real-runtime/config/system.yaml --output artifacts/b11-human-source.json --draft-output artifacts/b11-human-draft.json
# UI载入human-source，填写/封存/导出真人JSON后，以下才可能得到真实开发集指标
.venv/bin/python -m scripts.analyze_b1 --frozen-report artifacts/p037-b1/real-report.json --source-descriptor artifacts/b11-human-source.json --review /本机路径/person-a.json --output artifacts/b11-person-a-evaluation.json
# 第二位确实提供时增加 --second-review /本机路径/person-b.json
```

报告、标注、逐帧PTS和完整日志均为私有输入/结果；不要推送公共GitHub。公共Demo只含代码、生成素材源描述和脱敏汇总，不附工业媒体或真人事件。
