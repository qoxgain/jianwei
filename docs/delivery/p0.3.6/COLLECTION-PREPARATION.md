# 正式独立数据采集准备

已实现草稿生成与只读来源关系审查脚本 scripts/plan_independent_collection.py。例子 examples/independent-collection-p036.yaml 仅是待填采集计划，不是可直接导入或已获准的数据集清单；原片SHA、物理机位、时间、会话、人员匿名编码、谱系及审核均保持未知/pending。

按单一固定机位、稳定视角规划互斥会话，建议增加独立日期、班次、人员和操作实例。草稿按当前配置的train/calibration及正式协议会话数门槛安排最少槽位；未登记协议时仅示例2train+1calibration+2test，明确不是统计充分性或批准。已有九段开发资料不重新封存，工位1–7分别研究，服装两片不自动当独立。

`--review-manifest` 只检查声明的根/会话/视角、近重复审核及同机位同时间但不同会话的待核查冲突，不读取视频或特征。不同文件SHA不自动证明独立，工具不代替人工审查或正式准入。协议预登记仍由system.yaml的research_protocol完成，P0.3.5原门槛保持不变；无新数据时正式研究/P0.4继续blocked。

4项定向测试通过：草稿不伪造、正式test不读特征、同源转码不增加会话、采集身份冲突待审。CLI采用新输出文件且拒绝覆盖配置/知识/原清单；YAML元数据有大小和来源数上限。未实际采集新录像或核实现场记录。
