# P0.1 交付：配置与知识工作台

本步为见微 V3 的第一个可验收研发切片。P0 自学习闭环尚未完成。用户当前暂时没有真实数据，下一步先实现 P0.2 接入功能与示例流程。

## 查看与运行

- [交互 Demo 压缩包](../../demo/jianwei-p0.1-demo.zip)：下载、解压后在浏览器打开 `index.html`。
- [单文件 HTML](../../demo/jianwei-p0.1.html)、[场景概览截图](../../demo/overview.png)、[编辑器截图](../../demo/editor.png)、[手机布局截图](../../demo/mobile.png)。
- 完整代码分支：`codex/p0-1-foundation`。
- 后端模式：仓库根目录运行 `bash scripts/install.sh`，随后 `bash scripts/start.sh`。地址来自 `config/system.yaml`；当前仅运行单用户本地 demo。

独立 Demo 不连接 API、相机或模型，候选仅存在浏览器本地存储。完整后端把候选写入 SQLite。两种模式都不会将候选自动发布为运行知识。

## 已实现

1. React/TypeScript 深色工作台：场景概览、动作/SOP 编辑、环境检查、研发进度；包含桌面与手机布局。
2. 唯一配置加载器：严格字段、YAML 重复键与类型、env 引用、路径解析、脱敏配置快照和 hash。
3. demo/lab/site 静态检查；前置条件单独报告。live 禁止 synthetic/mock，环境变量解析后的地址也再次校验。缺少功能或资源不伪造就绪。
4. 动作表单与 YAML 联动；导入/导出、语义校验、变更与影响预览。暂时无效的字段保持可编辑；结构损坏时保留原 YAML 供修复。
5. 候选版本不可变保存、相同内容去重、过期基线冲突、版本 JSON/YAML 读取、审计事件。原始知识文件不被修改。
6. SQLAlchemy/Alembic 基础迁移：配置快照、知识版本、审计三张业务表；启动升级、重启恢复和事务回滚。
7. API 与 CLI；前端同源提供。RFC 8785 统一浏览器/Python hash，产品 YAML 按 YAML 1.2 core 解析。
8. 锁定依赖、安装/启动脚本、Schema 导出、自动检查工作流及独立 HTML/ZIP 打包。

核心实现路径：`apps/api`、`apps/web`、`packages/config`、`packages/contracts`、`packages/knowledge`、`infra`、`jianwei`、`scripts`。

## 输入与效果边界

- 输入：研发交接包里的服装示例知识；6 个动作定义（5 个示例动作与 1 个拉链草案），5 个 SOP 节点。
- 真实视频、独立周期、人工评测事件：未提供。
- 人工标注分钟：不适用，本步未执行真实样本标注。
- 数据划分/生产权重/模型指标：未执行；不能给出准确率或学习提升。
- 合成工具的独立复现记录见 [reference-baseline.json](reference-baseline.json)，不得作为真实工业效果。
- 当前不包含相机、视频导入、特征提取、训练、模型发布、生产鉴权或完整业务表。
- 知识包中的已定义动作仍是研发示例，正式 SOP 与真实效果需后续业务确认和数据验收。

## 建议本步验收

1. 打开 Demo，查看场景、动作与能力边界。
2. 修改“检查口袋”的名称或证据，查看 YAML 是否同步。
3. 点击“校验并预览”，核对稳定 ID、变更字段及影响说明。
4. 保存候选并刷新，在版本记录查看或下载；确认原知识基线仍保留。
5. 输入重复字段或非法 SOP 引用，确认明确报错且不能保存。
6. 查看 demo/lab/site 的检查差异，确认页面没有伪造现场运行或识别指标。

按用户要求，完成本步查看和反馈后继续 P0.2。下一步先提供 MP4/NPZ 导入接口、完整周期与时间戳检查、幂等及示例流程；真实输入可后补，真实效果保持待验证。
