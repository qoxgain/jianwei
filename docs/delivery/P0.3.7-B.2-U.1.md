## 2. 失败原因分类：证据与假设分开

| 类别 | 已有证据 | 能否定为根因 |
|---|---|---|
| 数据量/独立性不足 | 单源118.5秒，校准/回放各26窗，预测仅19/17对且彼此相关；完整重复作业周期未确认；新会话记录缺失 | 明确的验证能力限制，不能单凭它证明算法本来有效 |
| 信号/干扰 | 背景存在光照/衣物污染；部分操作表示同样不超纯时间打乱；轻量ROI偏移敏感 | 动作/衣物形变/阴影/相机运动的贡献尚不能分离 |
| 表征适配 | 手部R3D回放噪声最小一致性0.182；帧差/块运动回放为0；R3D的均值预测优于历史续接 | 不支持“深度一定更好”或“廉价特征已更准”；不能跨PCA空间直接比MSE排名 |
| 搜索限制 | 2/4/6窗对应3/5/7秒原始支持；最多8原型，块运动触顶；4窗分块保留短局部形状 | 对长工序或对象状态不足只是可检验假设，未通过加大搜索预算证明 |
| 评价目标混合 | 重复特征可以存在却没有未来特征预测价值；固定分段稳定是构造性质；分块对照保留内容 | 应分离新问题，但9种操作表示连纯时间打乱超额0.02也未通过，不能只删除预测要求“救活”旧结果 |
| 原型退化 | 帧差最大原型占匹配窗100%，但仅占总窗15.4%；背景R3D总覆盖7.7% | 条件单一性与占据全片不同；本轮没有证据认定发生全时段单原型坍缩 |

所有表示共用手部帧差活动资格筛选，“global_r3d”不是完全不依赖局部信息的端到端消融。边界更多、重复更多、动态幅度更大都不能代替动作真值。无动作标签不妨碍本轮开发诊断，但当前资料不能证明真实动作身份或准确率。旧录像已被观察多轮，所有历史比较仅回顾性探索。

## 5. 技术路线决策

- **现在优先补数据**：固定相机、可信会话、重复完整操作与干净背景。短时间单件状态演进和视角漂移无法用增加模型规模解决研究设计问题。
- **廉价ROI运动保留为主基线**：现成帧差/块运动成本低，便于定位阴影/机位混杂。但当前偏移/扰动不稳定，不能宣称动作精度优于R3D。后续先检查新会话对照收益，不增加变体数量。
- **R3D保留固定比较，不扩大投入**：部分表示扰动下较稳，但当前没有超均值预测/打乱的可靠收益。B.1提取约1,097秒远高于缓存分析约5秒；成本只支持按需精查/缓存建议，不能当准确性结论。
- **Matrix Profile适合短有界子序列候选**：当前精确搜索能发现特征相似性，但不等于完整SOP工序、对象状态或长作业周期。若新固定会话中仍不超时间/背景对照，应暂停将该表示作为动作记忆，而不是继续放宽阈值。
- **对象状态/手—工件交互只是下一假设**：如果相同运动对应不同工件状态，研究“是否需要把状态与运动分开”比更大时序模型更具体。先获得新数据上的反例，不在本轮引入检测器/大模型或缺标签监督训练。
- **持续更新记忆目前没有合格表示**：旧52个全部保留为失败；A/B任一将来代理通过也不自动生产入库。现阶段没有充分证据投入更复杂时序模型或进入B.3。
