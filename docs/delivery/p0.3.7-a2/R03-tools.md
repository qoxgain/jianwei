# A.2 R03 非空工具版本与v5配方

固定5f150e7使用生成的ffmpeg/ffprobe脚本实际返回空格/换行；旧实现均接受纯空白版本。新实现去除空行，按被探测工具名称寻找有效版本记录，要求version之后有可打印、非空版本标记；ffmpeg输出不能代替ffprobe。保留实际内容前后重哈希、首次缺失、执行中消失、超时及内容替换失败语义。

新生产身份为p037-a2-feature-production-v5，既有v1—v4配方、特征、权重及报告不改写。相同路径/大小/mtime替换测试改用有效的对应工具版本格式，继续验证内容SHA变化；未删除旧反例或降低检查。

19项新增用例，连同旧重哈希/探测边界共29项通过，包括实际安装工具的版本记录。全量回归与CI另见A.2总报告。
