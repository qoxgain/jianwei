# A.2 R01 可撤销、执行者绑定的文件租约

固定5f150e7已用真实flock复现：在async_hold中创建的子任务继承ContextVar，父作用域退出后由另一描述符取得同一文件锁；子任务仍held=True并进入保护区域写入生成标记。这是实际锁保护失效，不是仅检查上下文值。

新租约将授权绑定到PID、线程及异步任务身份，并支持撤销。复制ContextVar不会将所有权授给另一任务；父退出/取消后旧授权立即失效。run_sync显式给指定工作线程一个短期授权，同步嵌套访问仍可重入。物理锁资源以引用计数保留：若原生asyncio取消已返回但受控工作线程尚未结束，父授权已撤销、工作线程的既有授权仍在真实锁保护下，直到工作finally结束才关闭锁。排队而尚未开始的桥接不能从已撤销父租约新取授权。

7项新增真实锁测试覆盖父退出/取消、子任务仍运行、活跃父下的子任务拒绝、受控桥接与撤销后上下文、普通未授权offload、AnyIO及原生asyncio取消。连同原两线程/媒体、A.2备份、保存点/提交闸门共58项通过。异步锁等待仍为LOCK_NB加异步轮询，不占AnyIO工作令牌；没有扩大线程池。

同步hold不得跨异步任务借用；应用需调用受控run_sync取得合法线程授权。没有新增生产服务或真实封存数据访问。全量与真实浏览器回归待A.2总报告记录。
