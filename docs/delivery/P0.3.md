## 本次实现

- 从成功导入形成不可变研究快照，锁定来源分区、缓存和版本，拒绝 test 进入训练请求。
- train 内标准化、PCA、匿名聚类、变化点阈值；持久性、经验转移、ridge、可训练两层因果 TCN，以及目标打乱负对照。
- calibration 按来源等权选模；独立入口读取封存 test。先持久写预测、再读未来目标，记录实际 horizon；不跨周期、时间域和质量缺口。
- 数值权重保存/重载、版本指纹、异步研究任务、恢复/重试、场景 API、CLI 和研究页面。全部模型仅为候选。
- 数据接入页可选择整个原始来源的分区；四场景不依赖动作标签或 SOP。旧知识、导入接口和 source split 继续保留。

数值训练按源内容 hash 排序，避免随机导入 ID 改变拟合顺序。新数据库中相同合成输入经过四个场景，生成一致的权重 SHA；不同作用域的模型元数据仍独立。

## 四场景合成研究

四场景复用相同八个合成来源：4 train、2 calibration、2 test；每源两个完整固定周期。每场景实际使用 376 个训练窗口、188 个校准窗口和188 个测试窗口；这些窗口互相关联，不能当成独立视频。没有把四场景重复运行算作 32 个独立来源。

| 预先固定的模型 | 封存 test 按源平均归一化特征 MSE |
|---|---:|
| Ridge（由 calibration 选中） | 0.003652 |
| 持久性 | 0.663904 |
| 因果 TCN | 0.798026 |
| 经验转移 | 0.905470 |
| 打乱目标 Ridge | 2.419453 |

TCN 参数确实更新，训练损失从32.5698降到20.6678，但这次没有胜过 ridge 或持久性。保留该结果，未针对 test 调参。PCA 16维保留99.939%的训练方差；这只是所构造合成系统的机制证据，不是现场准确率或科研泛化结论。
