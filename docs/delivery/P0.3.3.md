## 几何、观察窗口和回查

显示矩阵只应用一次：`-noautorotate`后按原rotation显式旋转，校正SAR，长边有界缩放。岗2的1920×1080、−90°原片得到360×640显示RGB；224长边诊断为126×224。ROI坐标属于旋转/SAR后的显示图。0/±90/180度、非方形像素、像素颜色/ROI、原帧PTS均有回归。正式R3D后续仍执行已固定的官方128×171 resize/112中心裁剪配方，其版本写入特征空间。

20.44秒testShort保留实际结束时间，显式`p033-observation-v1`允许尾部提特征；`complete=false`、`business_cycle_verified=false`。观察窗口不等于人工确认业务周期。确认机位/会话必须与研究清单一致；全时域视角审查完整覆盖、无重叠才可过研究门槛。

Chromium无法直接解码本批HEVC视频（有时长不代表有画面）。有界本地H.264兼容预览保留原SHA谱系、逐packet PTS一致，去除旋转元数据避免二次旋转；视频专用无音频，不作为特征输入。共享512MiB预览缓存预算、600秒生成期限、单线程和文件锁由配置控制。[岗2实际预览记录](p0.3.3/portrait-preview.json)显示360×640，原4,422帧PTS一致；浏览器实际播放及10秒定位通过。
