## 本轮实现与修复

- 研究页/API/CLI 按已登记导入 ID 预检采集审查、作用域、整源分区、独立来源、完整周期与因果窗口。训练和独立评估分别报告准入条件，支持导出结果。
- 预检复用实际训练的来源快照、时间窗口和候选模型规则；只读元数据，不打开特征文件、不读取 test 值、不训练、不创建任务、不改变源分区或知识。模型、缓存字节和数值在执行时继续校验。
- 按真实导入导出采集记录草稿；未知日期/相机/会话/审查人保持空值，审查保持 pending，原片谱系必须由采集记录确认。
- 修复空白方法/证据说明能通过审查确认的问题。抽取共享窗口元数据校验，补强完整周期及有效行引用一致性。
- 四场景共用实现，支持零动作标签和无 SOP。离线 Demo 展示实际合成预检记录，真实操作走 API。

没有新增数据库 revision，也没有建设训练调度或权限平台。算法代码摘要因共享校验变更而更新，旧候选保留原版本；跨代码版本直接评估会被既有版本规则阻断，应使用原版本复现或在新版本建立候选。训练算法与配置参数未改写。

视频仍为一个 `unassigned` 来源。有效窗口覆盖 0–60 秒，即原片 118.5 秒的 **50.63%**；尾部不完整周期按既有规则排除。117 个片段、17 个分段都不是独立采集样本，也不是动作真值。

## 后续研究

1. 取得独立原始录像及真实采集记录，先核验同源/同会话/近重复，再固定全量 train/calibration/test 清单。
2. 至少 2 train + 1 calibration + 1 test 独立会话可打通软件；科研结论需要更多日期/人员/会话覆盖，不能以四个来源替代统计充分性。
3. 固定编码器与特征空间，运行预检；只用 train 拟合，用 calibration 选模，固定候选后显式运行封存 test。按来源报告五模型和各预测时距，保留失败及负结果。
4. 真实多源实验可复现、因果隔离通过、效果边界明确后再评审 P0.4。当前不宣称现场动作识别、SOP 合规效果或抗遗忘能力。
