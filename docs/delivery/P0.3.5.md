`temporal.research_protocol` 为可选严格配置；真实研究要求实际登记人、带时区时间、主要指标、双对照、会话下限和改善门槛。缺配置时阻断，不自动代填。新增只读协议 API，训练在读取特征前固定完整来源分区、配置/知识/代码/实际特征配方，产出 `protocol.json`，绑定候选模型。旧配置无此字段时原配置哈希不变，历史报告仍可读。

正式研究核对已执行的正式冻结 ONNX、编码器版本、采样、预处理、ROI、维度和特征空间。旧稀疏缓存、诊断编码器、仅外部声明的特征不能冒充新协议执行证据。模型真实性仍依赖受信任的服务端导出和登记流程；元数据不是外部认证系统。

按独立会话等权报告每跨度 MSE、余弦、匿名状态 NLL/Brier；配对 bootstrap 重采样整个会话。会话不足或对照误差接近零时区间为空，明确 blocked。固定候选须同时满足两项预登记改善门槛；校准不是最终效果，合成始终 mechanism_only。门槛不会自动激活模型或准入 P0.4。

封存保护使用原数据库追加审计：事务内按租户及来源/根/会话预留，首次特征读取前持久化消费。读取后失败、重启、换模型或协议均不能重新使用同一封存资料；幂等请求只返回原任务。历史真实训练、校准、评估来源也不能通过转码重新变为封存数据。未固定候选或准入失败时不检查 test 因果窗口，页面显示“未检查”。此保护依赖数据库记录保留，不是生产权限或防篡改平台。

## 真实资料的结论

[逐来源缺项与版本审计](p0.3.5/research-audit.json)重放已提交的九份稀疏清单和短片密采样清单：**9 个原视频、10 个特征版本、0 个已核验独立采集会话**。九份稀疏版本仍为 0 个联合因果窗口，密采样短片仍为 37 个片段、16 个窗口。这是元数据复核，本轮没有重新编码或完整解码九段视频，没有读取真实特征值或执行真实训练/评估。

仍缺物理机位、稳定视角、带时区采集时间、独立会话与近重复关系审核，以及预先封存的独立 train/calibration/test 资料。现有九段已用于开发，不重新声明为封存验收；7 个工位不按 5/1/1 冒充同视角重复采样。两个合成测试协议仅覆盖代码的充分/不足分支，均不构成真实效果，主配置和真实门槛没有降低。

## 查看与复现

[下载 P0.3.5 Demo](../demo/p0.3.5/jianwei-p0.3.5-demo.zip)，解压后打开 `index.html`，选择无标签观察→时序研究。可切换模型显示与指标、查看会话表并导出报告；包内另附真实资料缺项审计和已校验的合成候选权重。若浏览器限制本地文件，在解压目录执行 `python -m http.server 8080 --bind 127.0.0.1`，本机访问 `http://127.0.0.1:8080`。这不是公网部署地址，真实上传、协议预览及研究任务需要本地 API。

```bash
.venv/bin/python -m pytest tests -q
.venv/bin/python -m unittest discover -s reference/tests -v
npm --prefix apps/web test
npm --prefix apps/web run build
npm --prefix apps/web run build:demo
.venv/bin/python tests/browser_temporal.py --serve-isolated --chromium /usr/bin/chromium --output artifacts/p035-regression
.venv/bin/python tests/browser_research_protocol.py --chromium /usr/bin/chromium --output artifacts/p035-browser
.venv/bin/python -m scripts.package_research_demo
```

默认未登记真实协议；启动服务后进入时序研究即可看到阻断原因。元数据 CLI 支持 `python -m scripts.audit_research_protocol --help`；审计 blocked 返回 2，输出不覆盖配置、知识、原始清单或不同内容的已有报告。

未新增数据库迁移，配置/知识/原始数据字节不变。新增实际配方元数据会产生新的真实研究快照，旧候选需保留原代码/配置复现，不能默认为已满足新协议。后续按[现场研究任务](../plans/P0.3.5-next.md)和[执行指令](../plans/P0.3.5-Codex.txt)补独立数据；SOP 原文与人工映射流程继续可用，仪器要求仍须独立证据。动作语义、自动 SOP 判罚、RTSP、生产鉴权和 P0.4 不属于本次交付。
