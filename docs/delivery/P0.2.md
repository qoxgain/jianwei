## 已实现

| 范围 | 行为 |
|---|---|
| 输入 | 实际字节受限的 MP4/NPZ 上传，哈希和用途登记，不接受任意服务器路径 |
| 持久任务 | SQLite queued/running/succeeded/blocked/failed，幂等、重启恢复、重试、配置变化阻塞 |
| 视频 | 原始 PTS、实际 FFmpeg 解码、亮度/对比度与缺帧门槛，缺口和重置隔离 |
| 场景 | 四场景 source/context/episode policy 真校验，无动作或 SOP 也可接入 |
| NPZ | 禁 pickle、严格数组/ZIP/体积/有限数校验，CPU 缓存，外部来源声明与核验分离 |
| 编码器 | 可选冻结 ONNX CPU，实际文件 SHA 锁定及输入输出检查，无权重不生成随机向量 |
| 数据隔离 | 同租户原视频跨场景共享分区，拒绝 train/test 冲突，未核验来源不能继承训练分区 |
| 界面 | 上传、示例、轮询、任务详情、清单下载、四场景桌面与手机布局 |

source_hash 与 artifact_hash 分开；编码器上传只用于指纹。没有原视频核验的 NPZ 保持未分配，指纹匹配不证明向量的生产链。没有 UTC 锚点时保持 unknown，不用文件时间补造采集时间。完整周期与质量不合格行保留拒绝原因。

修复并验证了两类来源/时间漏洞：未核验特征不能继承已分配源组；独立 NPZ 的局部 d0 不等同于原视频同一时间域。跨独立连续段的未来配对保守拒绝。
