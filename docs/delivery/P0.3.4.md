## 零训练对的原因与实测修正

2 秒步长的历史在 16 秒结束，0.5 秒预测要求目标在 16.5 秒开始，现有网格下第一个目标是 18 秒，偏差 1.5 秒，超过 1 秒容差。联合窗口必须满足全部预测跨度。20.44 秒短片还受尾部未来长度限制。

显式研究配置恢复根 `system.yaml` 的 **clip=2s、stride=0.5s、16帧、history=8、horizons=0.5/2/5s**，保持 1 秒容差。理想连续网格需要至少 12.5 秒才能形成第一个联合窗口；质量、缺行、时间域及 episode 屏障仍有效。

## 本轮功能

1. 研究预检返回当前配置理想网格、逐来源实际时间诊断、逐预测跨度计数、首个目标偏差、质量/尾部/资源抽样原因以及可追溯哈希。无需读取向量值，不创建研究任务。
2. 页面显示这些解释，区分观察窗口、完整窗口与已核验业务周期。未分区来源即使已有因果窗口仍不能训练。历史离线 JSON 不需要添加新字段即可显示。
3. 封存 test 不提供采样选参诊断；原独立评估预检继续使用已固定模型自己的 learning/settings。训练、评估、版本隔离和因果选择算法未变，`packages/temporal` 未修改。
4. 新增元数据 CLI；显式 `--research` 配置工厂保留主配置采样和预测策略，不相容时拒绝。默认工程配置仍为 2 秒步长。`--encoder-report` 明确绑定本次正式冻结导出，防止误认历史字节。
5. 修复配置工厂原先先覆盖知识、后检查配置冲突的问题：现在先检查所有目标文件，存在人工修改即拒绝，幂等执行不覆盖用户修订。

## 复现

```bash
git lfs pull --include='datasets/video_samples/garment_quality/videos/*.mp4' --exclude=''
.venv/bin/python -m pip install -r requirements-pretrained.txt --extra-index-url https://download.pytorch.org/whl/cpu
.venv/bin/python scripts/export_pretrained_encoder.py --download --report artifacts/encoder-export.json
.venv/bin/python -m scripts.prepare_video_dataset --research --output-dir artifacts/p034-runtime --encoder-report artifacts/encoder-export.json
.venv/bin/python -m scripts.validate_video_dataset --config artifacts/p034-runtime/config/system.yaml --output artifacts/p034-real --asset garment_test_short --skip-default-limit
.venv/bin/python -m scripts.audit_temporal_sampling --config artifacts/p034-runtime/config/system.yaml --manifest artifacts/p034-real/garment_test_short/manifest.json --output artifacts/p034-real/sampling.json
.venv/bin/python -m jianwei serve --config artifacts/p034-runtime/config/system.yaml --profile demo
```

打开 `http://127.0.0.1:18053` → 无标签观察 → 时序研究 → 选中来源 → 检查选中来源。CLI audit 返回 0 只表示选中的开发清单都有因果窗口；返回 2 表示仍有零窗口，均不是研究准入结果。配置改变不会更新旧缓存；必须重提特征，不可就地改清单时间戳。
