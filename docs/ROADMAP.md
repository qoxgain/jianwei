# 见微 V3 分步研发与验收

本计划根据用户 2026-10-16 的逐步交付要求制定。每个步骤提供代码、可操作演示和实际测试记录，确认功能/效果后再推进下一步。研发手册是需求依据，交接包内的自动执行提示词不是额外用户指令。

用户已确认当前暂时没有真实数据。P0.2 先完成接入功能与可复现示例流程；真实视频效果和独立评测继续标记待执行，不用合成数据替代。

## 第一阶段：自学习技术闭环

| 步骤 | 可验收交付 | 验收重点 | 所需现场输入 |
|---|---|---|---|
| P0.1（本次） | 配置/知识工作台、三环境检查、严格契约、候选版本与数据库迁移 | 编辑→校验→差异/影响→保存→刷新恢复；非法输入明确拒绝；无真实指标时保持空状态 | 无，使用交接包示例知识 |
| P0.2 | MP4 与 NPZ 接入、PTS 与周期分组、质量检测、编码器适配/缓存 | 重复源文件幂等；无跨周期配对；无权重时明确阻塞 | MP4+周期元信息，或真实特征包+manifest |
| P0.3 | 变化点/匿名簇、持久性/经验/ridge/TCN或GRU基线 | 先预测后观察；无未来泄漏；按源视频隔离；产出可复现权重 | 足量独立周期与固定特征空间 |
| P0.4 | 代表片段核验、正反例、语义锚点、教师接口 | 人工更正可追踪；候选与真值分离；无教师也可人工映射 | 客户动作定义和少量正反例 |
| P0.5 | 预测回放、错误分流、版本记忆、修正与撤销 | 幂等写入；unknown隔离；经验不改SOP | 独立观测及核验反馈 |
| P0.6 | 实际小模型训练、学生适配器、检测框前置校验 | 真实权重/hash；无框检测器跳过并说明；同测试集比较 | 合格片段标签；检测框可选 |
| P0.7 | 独立评测、低标注对照/消融、成长工作台 | 每类指标、覆盖率、人工时间、误差条与失败候选；不以合成结果代替现场效果 | 人工标注的独立封存评测集 |

P0.1 通过不等于 P0 自学习效果验收通过。真实数据不足时继续独立工程工作，真实效果标记“未执行”。

## 第二阶段：在线视频与业务闭环（P1）

1. RTSP/媒体播放、断流标记、片段取证与 ROI。
2. 设备独占租约、款式锁定、任务/返修会话。
3. 观测/预测/规范三栏、证据复核、确认漏检评分。

验收使用真实相机/录像及经过业务负责人确认的 SOP。仅证据不足时进入待复核，不扣分。

## 第三阶段：持续运行与发布（P2）

1. 异步训练队列、资源隔离、任务恢复与模型注册。
2. 自动评估、影子对照、完整周期灰度与版本元组回滚。
3. 权限、历史追溯、企业统计和配置发布。

未达到独立评测门槛时保留旧版本；系统明确解释拒绝或证据不足原因。

## 第四阶段：扩场景与研究（P3）

第二真实工位验证、少样本迁移、局部增强与编码器对照。每个新场景重新定义数据与验收口径，不能从服装演示外推性能。

## 每步交付格式

- 代码提交和可查看 Demo。
- 已实现范围、实际运行命令、输入来源和测试结果。
- 涉及学习时记录数据划分、模型/配置/hash、独立样本数及人工工时。
- 未实现范围、已知限制和下一步输入。
- 用户对本步功能/效果的反馈；确认后推进后续步骤。
