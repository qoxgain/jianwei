# P0.3.4 后续：固定采样协议与真实多会话研究验收

目标是主线 A 方向2的真实因果时序学习；方向1提供可靠冻结特征，方向5的少样本适配在独立效果成立后推进。维持通用无标签、无SOP启动。P0.4 仍未准入。

## T0：保存基线与采样协议

读取当前 HEAD、AGENTS.md、P0.3.4 交付及现有数据目录，记录配置、知识、编码器 checkpoint/ONNX、预处理、特征空间、代码、来源和协议哈希。不覆盖历史材料。

本次验证采用主配置 clip=2s、stride=0.5s、16帧、history=8、horizons=0.5/2/5s、tolerance=1000ms。37 片段/16 窗口只验证短片的时间覆盖。先冻结研究协议，再批量提取；若研究问题要求别的采样或跨度，只能在开发/训练资料上另立版本，不能看封存测试选参数或放宽容差凑通过。特征更换后重提整个对应来源，不混用不同哈希缓存。

## T1：独立采集与完整记录

由现场提供真实固定机位录像与记录，先选 1–2 个重复动作清晰的视角分别研究。每个视角至少 **2 train + 1 calibration + 1 test 独立采集会话**；这是软件最低门槛，不是统计充分性。尽量增加独立日期、班次和操作实例，以独立会话数而非片段数规划样本量。

记录并审查 `physical_camera_id`、`stable_view_id`、`camera_id`、`view_id`、带时区采集时间、`capture_session_id`、根视频与派生关系、原文件 SHA、近重复核验、视角区间和时间域。移动或遮挡区间保持 excluded/unreviewed。业务周期只有经过人工边界核验才能标为 verified；无标签观察窗口继续保持其原契约，不能冒充完整业务周期。

岗1–岗7是不同工位，不能直接按 5/1/1 划分并宣称同分布独立验证。`test` 和 `testShort` 是否截片/近重复需实证确认；文件名和哈希不同不证明独立。现有九片已用于开发，可继续探索与工程回归，不再作为新的封存测试。

## T2：固定分区、批量提取与准入

先用现有采集记录草稿功能生成待填记录，再由有依据的现场记录补全并审核 `temporal.dataset_manifest`。未知值保留空值，不能由 Codex 猜测、批量勾选确认或伪造会话。

逐来源通过正式冻结编码器重提特征，产出上传/解码/编码耗时、峰值资源、质量排除、原 SHA 与新缓存 SHA。按租户、场景、视角和特征空间分组；不跨边界配对。运行采样诊断和研究准入，开发数据有窗口但来源不齐时保持 blocked。

封存 test 从划分起禁止用于候选选择、PCA/归一化/聚类拟合和阈值标定；不使用采样诊断接口查看 test 来决定协议。只在模型、数据协议、指标和准入阈值冻结后，通过已固定模型的独立评估路径处理。

## T3：真实学习与可复现对照

保留 persistence、empirical、ridge、causal_tcn、shuffled_ridge 对照。只训练允许的小模型，冻结视觉编码器；归一化、PCA、匿名簇仅从 train 拟合，calibration 选模和定阈值。报告每个跨度和每个独立会话的 MSE、余弦、匿名状态 NLL/Brier、参数变化、训练/校准损失及权重重载结果。

先固定主要指标及相对持久性、打乱目标对照的通过标准，不能事后挑最好指标。对不确定性应按独立来源/会话计算，而非对同一视频的重叠窗口做独立 bootstrap。独立来源不足以支持区间估计时明确报告“不足以评估”，不能输出虚假的置信度。本轮 P0.3.4 未新实现多会话置信区间或研究发布门槛，应作为后续验收工作实现并测试。

test 只用于冻结后的最终评价，不反向改候选。测试后修订协议/模型须另设新封存测试。效果不成立时保留失败报告，继续开发/训练研究，不自动进入 P0.4。

## T4：SOP与语义的独立审核

保留现有 SOP 11 章节与 7 工位多对多来源定位与人工审批。负责人核实章节、步骤边界、编号/前缀/SAP争议；可见动作与规范要求分别记载。扭矩、安规、电性能和老化结果依赖可追溯仪器记录，不能仅凭画面推断合格。批准映射不生成视频真值，不激活规则、不作为自监督标签。

只有后续要验收动作/事件/分段语义时，另建人工标注与复核集。当前不宣称动作准确率、SOP合规率或跨行业泛化。无SOP安全事件与无标签场景持续纳入通用契约回归。

## 交付门槛

交付提交 SHA、CI、实际四场景/桌面/手机结果、每来源清单、冻结协议、真实训练/校准/独立测试报告、可重载权重、数据迁移记录和失败原因。工程通过与研究效果通过分别列出。没有新数据时完成可做的工程任务，输出缺失字段清单并保持研究 blocked；不要重跑合成示例来替代真实效果。

不扩大到 RTSP、完整多租户权限、自动SOP判罚、在线持续学习或教师自证。满足预注册独立效果门槛后再提交 P0.4 语义锚点与状态记忆任务。
