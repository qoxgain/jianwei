# 基于真实探索结果的下一步

先审阅两个报告和独立分支，不直接合并到原P0.3.5。

1. 单独修复AUD-01：按来源/会话再按episode分配窗口，容量不足在读取封存值/提交消费前阻断；增加9来源8预算、跨episode偏置反例。单独修复AUD-02：完整特征生产依赖/不可变构建进入协议与FeatureSpace版本绑定，保留旧配方与快照。
2. 排查隔离SQLite损坏事件与本环境文件系统/多进程I/O，尚无根因时不宣称数据库已修复；保留读失败原始响应，验证崩溃恢复和备份。实验文件模式是算法验证路径，不是替代生产持久性验收。
3. 算法继续以TrainMean、InitialTCN、ShuffledTCN为必要对照。尝试训练区间内的残差/变化量预测、足够感受野的时序头及运动/局部特征；所有新超参数只在开发/训练/validation中选择，失败结果保留。不能仅凭胜过Persistence或Ridge认定时序学习成功。
4. 现有九片继续标记回顾性开发资料，可做多种子敏感性研究，但不能反复在相同holdout选方案后称为新泛化验证。跨视频关系与视角可比性没有证据时C继续不执行。
5. 新增固定视角独立采集，真实登记相机、视角、时间、会话与根/派生关系，审核近重复；train/calibration/test按会话事前固定，新test事先封存且不用于选择采样/阈值。至少2train、1calibration、至少2test仅软件下限，应增加日期/班次/人员的独立样本支持稳定区间。
6. 可以设计P0.4的人工语义锚点、复核与版本接口；正式P0.4准入仍false，先解决独立真实效果门槛。不自动激活模型、SOP判罚或在线训练。
