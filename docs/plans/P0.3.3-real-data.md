主线A：大文件、HEVC、几何和时间契约对应方向1；匿名分段、未来状态预测与独立验证对应方向2；可追溯SOP候选、人工反馈和版本为方向5少样本适配准备输入。

交付通用接入修复、工位/视角与观察窗口契约、规范草稿复核、真实匿名探索和可复核证据。冻结基础编码器，只训练允许的小模型。不提前开发完整多租户权限、RTSP、自动持续训练器、全流程SOP判罚或Qwen自动语义定标。

素材搬迁、LFS路径兼容和初步SOP目录已完成，复用`datasets/video_samples`，不重新搬运或改写原片。详情见 [数据评估](../delivery/P0.3.3-data-review.md)。

## T0：冻结基线与复现

读AGENTS.md、本任务书、数据评估及`docs/DATASET-PROVENANCE.md`。记录实际HEAD、依赖、FFmpeg、模型和配置版本；拉取LFS实体，运行`audit_video_samples.py --full-decode`，核验10个资产SHA与9个视频帧数。未物化指针必须blocked。

保留历史P0.3.1/P0.3.2报告、ZIP、截图和哈希，新证据写新目录。继续四通用场景回归；公牛产线作为电子装配/无标签能力的配置实例，不新建行业专用引擎。

## T1：有界大文件接入

1. 用受校验的`system.yaml`测试副本显式启用512 MiB（536870912字节），覆盖最大原片；保留默认64 MiB拒绝行为。不在API/前端写死行业特例，不引入第二个运行参数真源。
2. 上传和哈希逐块执行，避免示例脚本`read_bytes()`让大文件重复驻留内存。保持磁盘、展开内存、帧数、时长限额、原子提交、失败清理、幂等及取消/重试。
3. 实际7个大文件通过允许配置导入；默认配置准确拒绝。验证超限、损坏、重复请求、取消/恢复，记录实际RSS、临时磁盘和耗时，不能把理论缓冲上界当RSS。
4. 上传/解码/特征阶段进度可见、刷新恢复任务。分别量测探测、解码和编码，配置有界阶段超时。本轮底层解码工业片约69–123秒，而当前probe配置60秒，需要按运行硬件验证；不关闭所有限额。

## T2：旋转、比例、PTS和特征版本

1. 探测display matrix/rotation、SAR，明确定义编码、显示、ROI和模型坐标。旋转只应用一次，不拉伸或双重旋转。
2. 当前1920×1080、-90°的视频按编码尺寸被缩放成横屏；长边224诊断应为126×224，现有输出224×126。正式模型按自己的输入配置处理，不能把诊断尺寸写死为所有编码器的契约。
3. 对0°、±90°、180°、非方形像素、ROI、颜色和原始帧索引做像素级回归；保持原始PTS、gap/reset/time-domain验证，不用frame_index/30代替，不转码覆盖原片。
4. 几何变化须更新preprocessing/feature-space/缓存与模型清单身份，重提不兼容特征。旧横屏回归和历史证据继续可追溯。导出诊断脚本也检查旋转假设。
5. 继续正式冻结R3D-18，核验checkpoint来源和SHA；实际推理生成512维特征，不用随机权重、mock或统计向量冒充。

## T3：工位、视角、会话与观察窗口

1. 分离logical source、物理camera、stable view、capture session、源文件/派生片与ROI policy。当前view摘要仅由source.id和ROI生成，不得所有工位复用file_01而错误同域。同一固定机位的独立日期记录保持相同视角。
2. 手机视角移动进入质量审查或人工稳定视角区间，不伪造新独立会话；镜头移动不等于PTS重置。全长区间标明可用、排除、未覆盖及原因。
3. actions/events为空、SOP为空仍可接入和提特征。完整观察窗口与经人工/外部信号确认的完整业务周期分开，固定60秒不能直接叫生产周期。
4. testShort只有20.44秒，技术接入应成功、有足够片段时可提特征；不足history+horizon的训练对排除。不可把整段文件伪造为完整周期，不可静默缩短全局窗口；策略变更有显式版本。
5. 电子装配需要external cycle，当前无周期记录时可进入无标签观察，业务SOP评测继续等待周期/工序边界。界面区分已接入和研究就绪。

## T4：SOP候选、证据与人工复核

1. 复用outline.draft.json和station-mapping.draft.json，每项保留文档SHA、PDF页码、原文范围、抽取版本和审查状态。26页由3页前置材料+23页正文构成，不把封面23页误报为错误。
2. 11个编号章节独立建模，工位与章节允许多对多。保留流程页工序数、跳号/重复编号、文档前缀和SAP编码疑点，工艺负责人确认前不纠正或激活。
3. 证据需求分为可见操作、需要近景细节、需要工具/仪器数据。扭矩、绝缘/耐压、电性能、老化结果不能从普通动作画面推断，缺证据输出insufficient_evidence，不判合格或违规。
4. observation、prediction、normative_expectation、human_annotation、semantic_candidate分别管理。SOP是期望，不是视频真值；机器候选与预测不能成为金标准。
5. 提供最小人工复核界面：回看原片时间段和PDF页码、修改映射、保留异议、批准/撤销审计及版本。草稿不自动启用，不向服装场景传播工业规范。

## T5：真实匿名探索和浏览器验收

7工位分别输出真实特征覆盖、匿名候选分段、代表片段、质量/排除区间；保持匿名ID，不强行命名成SOP动作。两个服装视频单独回归，不混成同视角训练集。

结果绑定source SHA、view、session状态、episode/window、feature space和预处理/模型版本。单视频探索使用unassigned，训练/测试分区不放松。报告覆盖率、可用训练对及簇分布，说明镜头运动混淆；无人工边界不报告动作F1、准确率或SOP合规率。

实际浏览器桌面/手机验收：大文件进度、错误提示、竖屏比例、中文路径、短片状态、无标签启动、原片时间跳转、SOP草稿状态；保存实际截图和机器结果。

## T6：独立来源研究验收

1. 先选1–2个重复周期清晰、固定机位的工位。每个目标研究作用域单独补采，当前软件最低2个train+1个calibration+1个test独立来源/会话；这是技术下限，科研结论还需多日期/人员和足够周期。
2. 记录真实采集时间/时区、原始根/父片、机位/视角/会话、周期边界来源、用途及近重复审查。不把容器creation_time自动转为已确认采集时间，不编造字段消除阻塞。
3. 禁止7个不同工位直接5/1/1划分。跨工位迁移需单独OOD协议、显式兼容策略和基线，不能关闭视角隔离让其通过。
4. 现有素材已用于开发，最终封存测试另采未参与调参的录像。预先固定manifest、主指标、基线、排除规则、阈值；训练拟合聚类/投影/小模型，校准定阈值，测试一次评估。查看测试后调参须更换新测试集。
5. 沿用normalized_feature_mse、original_feature_cosine、匿名状态NLL/Brier、source_macro_mse；对照persistence、empirical、ridge、causal_tcn及已有shuffled_ridge。复核时序打乱基线，按会话汇总误差/不确定性，不能把重叠窗口当独立样本增加显著性。
6. 动作边界、事件或SOP指标需要独立人工标注和复核。来源不足仍完成T1–T5并交付blocked清单，不停止已授权工程工作。
