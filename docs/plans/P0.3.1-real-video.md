# P0.3.1 真实视频与冻结编码器验收任务书

日期：2026-10-25。延续 P0.3，先完成真实输入研究门槛，再进入 P0.4 语义锚点。主线 A 对应方向 1 的可靠特征输入和方向 2 的无标注时序研究。

## 已有证据和缺口

用户上传 `examples/test.mp4`，源 SHA256 为 `a5ba7ed75052efd280114c382bd996d8a8a22b8664244fe7af99afb83300ce16`。118.5 秒、640×480、24 fps、2,844 帧、20,848,517 字节。抽帧可见桌面服装操作；尚无逐帧动作、业务周期或 SOP 合规真值。

P0.2 默认 128 MiB 解码预算会拒绝该视频；临时 512 MiB 配置能完整解码。无权重时明确阻塞；诊断 RGB 均值 ONNX 可产生 117 个有效片段，证明从真实字节到缓存的工程路径。默认无标注场景有一个完整 60 秒窗口和一个 58.5 秒尾部不完整窗口，后者不进入训练。这个窗口不等同于人工确认的完整服装检验周期。

正式视频编码器尚未就绪，单个来源不足以分成独立 train/calibration/test。P0.3 合成实验的数值结果不能移作本视频的准确率。

## 开发顺序与验收

| 任务 | Codex 应完成的工作 | 验收产物 |
|---|---|---|
| T0 冻结基线 | 保留上传源和已有报告；核对远端 HEAD、配置、依赖、数据分区；建立本视频回归用例 | 提交 SHA、源 hash、基线报告 |
| T1 有界视频处理 | 改进分块解码或有界帧采样，降低完整 RGB 临时展开量；仍用原始 PTS、质量门槛和明确时间域；不静默改小输入尺寸 | 本视频全部 2,844 帧时序核验；与原完整解码的片段/质量对照；峰值内存和临时磁盘实测；长视频限额测试 |
| T2 固定真实编码器 | 从可核验的官方发布选择兼容许可与计算预算的冻结视频表征模型；固定版本、下载来源、许可证和 SHA；实现/export ONNX 及预处理；禁止随机权重冒充 | 来源清单；输入 N×T×3×H×W/输出 N×D 契约；原框架与 ONNX 数值误差；不同片段向量非恒定；重载一致；缺权重仍阻塞 |
| T3 完成单视频验证 | 用正式冻结权重处理 test.mp4，核对源/特征/配置 hash；展示匿名时间线、覆盖率、尾部未纳入原因和可回查片段 | 实际特征缓存、导入报告、匿名候选预览；不计算动作准确率、不启用独立测试伪装 |
| T4 建立研究数据集 | 接入不同原始采集会话，先固定来源分组再训练；保留 camera/view/日期/来源关系，审查截片/转码造成的近重复 | 原始来源清单；同源派生片段归到同一组；固定训练、校准、封存测试；任何会话泄漏均阻断 |
| T5 真实无标注研究 | 固定特征空间，用 P0.3 五类模型比较；train 拟合所有统计量，calibration 选模；最后一次读取封存 test | 按源和 horizon 的误差、覆盖率、独立来源/周期数、简单基线与打乱对照；保留失败结论；小样本不足时只做探索报告 |
| T6 页面和回归 | 执行 P0.3 研究页面的四场景 API 与离线浏览器验收、桌面/移动端、刷新恢复、失败重试、权重/报告下载；补截图 | 无控制台异常、无横向溢出；实测截图与命令；后端/前端/旧参考测试和构建通过 |

T1、T6 可立即推进。T2 由开发执行模型选型与集成；如目标运行环境不能取得正式模型，保留明确阻塞和可复现下载/导出步骤。T3 依赖 T2。T4 所需额外现场录像不能通过生成或切割 test.mp4 代替；材料未到时继续完成独立工程任务，T5 真实效果保持待验证。

软件下限为 2 个 train + 1 个 calibration + 1 个 test 独立来源，仅用于通路验证。研究先规划多日期/人员的采集，不把软件下限写成“足够证明泛化”。一旦查看封存结果后继续针对其修改方案，应另保留新测试集。

## 范围边界

不扩建多租户权限、RTSP 推理、检测器、Qwen 自动标签、持续学习自动上线。四场景共享数据和算法；服装业务词、款号、评分继续在知识层。匿名簇不是动作类别，预测不是观测，SOP 不是训练标签。

P0.3.1 实测通过后进入 P0.4：代表片段和少量人工正反例建立版本化语义映射；Qwen 只提建议，人工核验记录独立保存。P0.5 才接连续状态记忆与预测/实际对照，P0.6—P0.7 再做少样本学生训练及抗遗忘独立评测。

## 给后续 Codex 的执行指令

以当前远端 `codex/p0-1-foundation` 为基线，先阅读 AGENTS.md、README、docs/TEMPORAL.md、P0.3 交付和本任务书。用户已授权继续开发及测试。先核对并保存现有工作，不覆盖用户上传视频；在现有工作分支分阶段提交，不合并 main、不部署。依 T0—T6 推进可执行任务，记录实际命令和结果。不得降格数据隔离、重新解释诊断编码器为真实模型，或以合成结果填补现场评测。遇到缺少模型/独立视频时指出具体依赖，完成其他已授权工程工作。最终交付代码 SHA、真实视频报告、实际模型/特征 hash、迁移/回归记录、浏览器截图和未通过的验收项。
