# P0.3.3 后续：固定视角采集与独立学习验收

当前工程接入与匿名探索已能处理本批九段视频。独立真实学习仍 blocked，不进入 P0.4。现有录像、采样画面和探索统计均已用于开发，不再作为最终封存测试。

1. 选定 1–2 个重复操作清晰的固定机位，各自建立独立研究作用域。记录真实 `physical_camera_id`、`stable_view_id`；不同工位不共用视角摘要。移动镜头区间以 `view_intervals` 标明 usable / excluded / unreviewed，不伪造新会话或 PTS 重置。
2. 每个作用域至少另采 2 个 train、1 个 calibration、1 个 test 独立采集会话；这是软件下限，不代表统计充分。补齐带时区时间、capture_session_id、原始根/派生片、近重复审核及必要的周期边界。当前七个工位不可直接 5/1/1 分区。
3. 在任何训练前固定 `temporal.dataset_manifest`、所有分区、预处理版本、指标与基线。确认导入的机位/会话/时间与清单完全一致，并审核完整时域。确认字段不接受推测填充。
4. 本轮 CPU 工程验收显式使用 clip=2s、stride=2s、16帧、512维。原预测跨度仍为 0.5/2/5s，目标容差为 1s；当前稀疏网格不能满足 0.5s 目标容差，**九片实际可用训练对均为0**。不要把有效特征数当作训练样本数。正式研究先确定更密的采样（如原0.5s步长）或预注册与采样网格对齐的预测跨度，再重提对应版本特征；不能为通过验收临时放宽目标容差或偷看测试。20.44s短片在当前历史长度与未来跨度下也无完整因果对。
5. 训练仅拟合允许的小模型；比较 persistence、empirical、ridge、causal_tcn 和 shuffled_ridge。校准集定阈值，封存测试一次评估；按独立来源/会话报告 normalized_feature_mse、original_feature_cosine、NLL/Brier、source_macro_mse 和不确定性。查看测试后再调参必须另采新测试集。
6. 工艺负责人复核11章节与7工位的多对多映射、编号/前缀/SAP疑点，以及真实步骤边界。扭矩、安规、电性能、老化提供可追溯仪器数据；画面操作不等于结果合格。SOP批准只记录审核，不激活、不生成视频真值。语义指标需要独立人工标注与复核。

可继续的工程工作：补采清单和数据核验、在固定方案下重提特征、排除区间审核、独立研究复现。不要提前增加自动SOP判罚、RTSP、生产鉴权或语义自证。只有独立真实学习验收通过后，再提出 P0.4 语义锚点任务。
