## 不可降低的规则

1. 训练请求只接受train/calibration导入ID；test通过独立评估请求读取。正规化、PCA、聚类、转移矩阵和可训练参数只fit train。calibration仅比较候选；test不选模型、不重新拟合。
2. 同一租户/场景/视角/特征空间；来源已核验或明确demo合成；同源只接受一个导入，避免重复片段重加权。训练、校准与test源组不相交。
3. 先固定清单hash，执行时验证数据库清单及实际缓存字节hash。拒绝未分区、未核验源、非有限特征、未知版本、跨租户、错误场景和超资源预算。
4. 历史与所有未来目标属于同一源、周期、时间域、实体；不跨质量屏蔽或缺口。`input_max <= issued < target_start < target_end`；实际目标时间和请求horizon均保留。
5. 离线回放先持久记录预测，再读取相应目标向量并追加观测。明确为因果离线回放，不声称实时部署。
6. 簇仅有匿名ID与版本；变化点和均匀分段只输出候选。未来特征误差、匿名状态概率与下一簇转移分别报告，不输出业务动作识别率。
7. 记录独立来源/周期数、覆盖率、每源和每预测窗口指标，防止将相邻窗口数量当独立样本数。使用固定随机种子；权重仅candidate，不自动激活。
8. P0.3不实现Qwen语义、学生分类器、持续学习发布或生产权限。旧P0.2导入/知识功能不得退化。

## 科学口径

PCA用于有界CPU研究，不改视觉编码器；必须记录保留方差和原特征空间重建误差。TCN采用左侧因果膨胀卷积，属于独立小模型；不声称复现论文完整结构。目标打乱只发生在train，是负对照，不写成真实未来观测。算法选择以calibration原空间误差为准，test报告保留全部预设基线。

参考：Bai等的[因果TCN研究](https://arxiv.org/abs/1803.01271)；scikit-learn官方[数据泄漏说明](https://scikit-learn.org/1.7/common_pitfalls.html)。实现独立使用锁定NumPy，不增加未锁定深度学习依赖。
