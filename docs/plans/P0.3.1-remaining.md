# P0.3.1 剩余验收与后续执行

接续 [本次交付](../delivery/P0.3.1.md)，T0/T1/T2/T3/T6 工程及单视频实测已完成，原任务书 T4 的实际数据集和 T5 的真实学习效果仍待验收。不得因为单视频探索页可用就跳到 P0.4。

1. 保留现有 `test.mp4`、官方模型/特征哈希及全部历史证据。当前视频采集会话、机位和日期待确认。收集不同原始采集会话的录像及机位/视角、带时区日期、人员和派生关系；切片、转码或重复上传不算独立来源。
2. 按 `temporal.dataset_manifest` 完成采集关系和人工近重复审查，先固定全部分区，再开始研究。最低 2 train + 1 calibration + 1 test 只证明软件通路；研究应覆盖多日期/人员并预先制定评价方案。
3. 固定 R3D-18 实际权重、预处理、采样、ROI 和特征空间。使用同一配置提取多来源特征，保留质量缺口、完整周期与源 hash。不可用本视频回顾性探索统计量初始化独立研究模型。
4. 用 P0.3 五类模型执行 train-only 拟合，calibration 选模，最后读取固定封存 test。报告各源、各 horizon 的误差/覆盖率、独立来源及周期数、简单基线与打乱对照。保留失败结论；无动作真值不写准确率。
5. 依据原任务书验收真实输入与学习效果后才进入 P0.4。若结果不足，继续采集与改进；已查看 test 后针对结果改方案时须保留新的封存测试集。不得用合成结果填补真实验收。

资料未到时可以维护复现、修复已发现工程问题，但不能虚构日期、审查人、来源数量或泛化结果。后续代码继续在 `codex/p0-1-foundation` 分阶段提交，不合并 main、不部署。
